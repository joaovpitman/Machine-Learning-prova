📖 Sobre o Projeto
Este repositório contém o projeto desenvolvido para a disciplina de Machine Learning, sob a orientação do professor Sergio Monteiro. O objetivo principal é aplicar conceitos e algoritmos de aprendizado de máquina para análise de dados, construção e validação de modelos preditivos.

🔧 Como Executar o Projeto
Clone o repositório:
```bash
   git clone https://github.com/seu-usuario/nome-do-repositorio.git
   cd nome-do-repositorio
   ```
Crie e ative um ambiente virtual (opcional, mas recomendado):
```bash
   python -m venv venv
   # No Windows:
   venv\Scripts\activate
   # No Linux/Mac:
   source venv/bin/activate
   ```
Instale as dependências:
```bash
   pip install -r requirements.txt
   ```
Execute os notebooks:
```bash
   jupyter notebook
   ```
